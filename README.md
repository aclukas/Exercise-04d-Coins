# 2D Platformer
Project 04, 3/14/26

A platformer whose goal is to collect all 10 coins! Move the character using WASD+Spacebar and kill all the enemies.

## Implementation
- New player sprite/animation made by me
- Animating the coin (juicy?)
- Large level
